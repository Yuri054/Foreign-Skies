# Flag sources

SVG sources for the flag pictures in `assets/flags` (drawn by `tools/build_flags.gd`).

- Most come from the [flag-icons](https://github.com/lipis/flag-icons) set (MIT licence, 4x3 versions, fetched
  from the npm package `flag-icons` 7.6.0) for nations whose 1914 flag matches today's: Albania, Austria
  (standing for Austria-Hungary's civil ensign), Belgium, Bulgaria, Denmark, Spain, France, Great Britain,
  Greece, Luxembourg, the Netherlands, Turkey (the Ottoman Empire), Portugal, Romania, Russia and Switzerland.
- Drawn by hand, because the 1914 flag differs from today's: Germany (the imperial black, white and red),
  Italy (with the Savoy shield), Serbia and Montenegro (the tricolours).

The flags themselves are not copyrightable designs; the MIT notice of flag-icons applies to its drawings.
